# Pocket-Finance-Ledger-Support

Pocket Finance Ledger is a private, offline personal finance tracker for iPhone and iPad.

## Support

If you have a question, found a problem, or want to suggest an improvement, please create a support request using the Issues section:

[Create a support request](https://github.com/iiyaa278-ctrl/Pocket-Finance-Ledger-Support/issues/new)

When reporting a problem, please include:

- Your iOS or iPadOS version
- Your device model
- A short description of the issue
- Steps that reproduce the issue

Please do not include personal financial information, receipt images, account balances, or other sensitive data.

## Privacy Policy

[View the Privacy Policy](https://www.termsfeed.com/live/21a863e2-1383-4292-9cf8-763af3e64d93)

Pocket Finance Ledger stores ledger data locally on the device and does not require account registration.
